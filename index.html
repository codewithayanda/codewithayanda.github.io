Cleared

Invoicing and VAT for South African small businesses

In development

A platform that helps small businesses invoice correctly, track what customers owe and stay on the right side of VAT, without having to be tax experts. The core flow already works end to end: register a business, add a customer, issue an invoice, record the payment and download the PDF.

  • VAT rules built in. Standard, zero-rated and exempt lines, with rates that carry the date they apply from.
  • Trustworthy records. Issued invoices are locked, numbered without gaps and written to an audit trail.
  • Multi-tenant. Many businesses share one platform and each sees only its own data.

AI Footprint

A VS Code extension for mindful AI-assisted coding

Open source · MIT

Helps developers stay honest about how much they lean on AI to write code. It notices large pastes and unusually fast typing, nudges gently and shows a live dashboard. It isn't anti-AI; it's pro-understanding.

  • Notices how code arrives. Clipboard-aware paste detection and per-language typing cadence.
  • Gentle by design. Three nudge levels with cooldowns, snooze and quiet time while debugging.
  • Private. A daily score, streak and dashboard, all stored locally and exportable.
  • TypeScript
  • VS Code Extension API
  • esbuild
  • ESLint
